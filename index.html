Local Eye Mask API

seedance2.0

人脸直过接口 — 上传图片或传图片 URL，自动遮挡眼睛（白底黑边方块），返回可访问结果图地址。全部本地处理。

在线试一下

遮挡框大小 5 （2≈眼睛，10≈整张脸，默认 5）
准备就绪，拖入或选择图片。
拖拽图片到这里 或点击选择 · 支持 jpg / png / webp

API 接口

POST /api/detect multipart/form-data BaseURL：…
字段说明
image 与 imageUrl 二选一。jpg / png / webp。处理时长边>1600 等比缩小；结果一律 .webp
imageUrl 与 image 二选一。http/https 图片 URL；服务端下载后走同一流水线；上限 20MB
detector 可选。onnx / haar / auto（自动选）；默认自动
noFace 可选。1 / true / yes 时跳过人脸、全图检眼（仅 Haar 生效）
singleEye 可选。每脸只遮一只眼。1 / true / yes 开，0 / false / no 关；省略默认开
size 可选。遮挡框大小 1–10：2≈眼睛大小，10≈整张脸；默认 5
